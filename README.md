# pythonDjango
Django python work files. It consists of day by day workouts what i tried at the time of learning python django framework.

Software Requirements:
 
 1.Install python and set the path
 
 2.Create a folder and open that path in your terminal.
 
 3.Run the following commands:
 
    a. py -m pip install --upgrade pip

	b. py -m pip install --user virtualenv

	c. py -m venv env

	d. .\env\Scripts\activate

 4.Run the django-admin command to start poject
    
	 django-admin startproject myproject
	 
	This will create folder named myproject and installed necessary files.

 5.Step inside the project directory that you have created
     
	   cd myproject

 6. Run a command to start the server.
 
       python3 manage.py runserver
	   
 7. send a string "Hello world" in httpresponse from index function.
